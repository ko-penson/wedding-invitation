# Wedding Invitation

参考画像のトンマナと、おふたりのコンセプト「AMPLIFY / 増幅」をもとにした、スマホ向けウェブ招待状のテンプレートです。

## 動画を差し替える

1. 無音のスライドショー動画を `assets/hero.mp4` という名前で保存
2. 必要なら、動画の読み込み前に表示する画像を `assets/hero-poster.jpg` として保存
3. `index.html` をブラウザで開く

動画がない状態でも、クリーム色の背景と文字は表示されます。

## 文言を差し替える

主な編集箇所は `index.html` です。

- `KOTA & CHIHARU`：ふたりの名前
- `2027.01.30 SAT`：日付、`13:00 - 16:30`：開催時間
- 会場名、住所、会場公式サイトへのリンク
- `2026年11月30日（月）`：仮の出欠回答期限
- RSVP / MESSAGE のリンク先

## 公開方法

このページは静的なHTML/CSS/JavaScriptなので、GitHub Pagesなどの静的ホスティングにそのまま載せられます。公開時は `outputs/wedding-invitation` の中身を、GitHubリポジトリのトップ階層に置いて `index.html` が直下にある状態にしてください。

公開後に発行されたURLを、LINEやメールでゲストに送る運用です。動画が大きい場合は、`hero.mp4` を十分に圧縮してからアップロードしてください。

Googleフォームを使う場合は、同フォルダの `google-form-setup.md` と `create-rsvp-form.gs` を参照してください。

専門用語を使わない手順は `かんたん操作ガイド.md` にまとめています。まずはこちらを読むのがおすすめです。

Google Fonts の `Yomogi` と `Caveat` を読み込んで、手描きの見た目を再現しています。オフラインで使う場合は、`styles.css` のフォント指定を端末内のフォントに変更してください。
